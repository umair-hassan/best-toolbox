It is important that you verify that your computer meets, or exceeds, the minimum system requirements for operation. 
If your system does not meet the minimum requirements, problems can occur while  running the application.

System Requirements 

Windows 7 SP1 or newer (including Windows 8, 8.1, and 8.1 Update 1)
Microsoft's .NET Framework 4.5 or higher
1GHz processor (dual-core recommended)
2GB of RAM

You can install Microsoft's .NET Framework 4.5 from the following link:

http://www.microsoft.com/en-us/download/details.aspx?id=30653
